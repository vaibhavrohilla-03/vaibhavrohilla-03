### 🛠️ Featured Engineering Work

*   **[SimpleContainer](https://github.com/vaibhavrohilla-03/SimpleContainer)**: A minimal container runtime built from scratch in **Go**. Orchestrates Linux primitives (Namespaces, pivot_root, chroot) for complete process and
  filesystem isolation.
*   **[Event-Driven Backtesting Engine](https://github.com/vaibhavrohilla-03/Option-Strategy-Backtesting-Engine)**: A high-performance options trading backtesting engine in **C++** with Python bindings exposed via PyBind11.
*   **[Market Data Dissemination Simulator](https://github.com/vaibhavrohilla-03/MarketData-Dissemination-Simulator)**: An L3 orderbook data dissemination simulator using **C++** and **gRPC** to model high-frequency, low-latency
  market data feeds.
*   **[AR Indoor Navigation System](https://github.com/vaibhavrohilla-03/AR-Indoor-Navigation-with-Cloud-Anchors)**: A spatial mapping application built in **C#**. Integrated Google Cloud Anchors and a **Firebase** backend for
  persistent data storage, allowing users to save and retrieve complex navigation routes.
